AWS Lambda & Serverless Computing

A learning project exploring serverless computing, AWS Lambda functions, Amazon API Gateway, and a simple serverless API.

Project Overview

⚡ Serverless Computing

Run application code without managing servers. AWS manages the underlying infrastructure.

λ AWS Lambda

Execute code in response to events with automatic scaling and usage-based billing.

🔗 API Gateway

Create and manage APIs that receive client requests and invoke backend services.

1. AWS Lambda Fundamentals

AWS Lambda runs code in response to events without requiring server management.

  • Event-driven execution
  • Automatic scaling
  • Managed runtime environment
  • Integration with AWS services
  • Pay for requests and compute time used

Sample Python Handler

import json

def lambda_handler(event, context):
    return {
        "statusCode": 200,
        "body": json.dumps({"message": "Hello from AWS Lambda!"})
    }

2. Amazon API Gateway

API Creation

Create HTTP or REST APIs and define routes such as GET /hello.

Lambda Integration

Configure an API route to invoke a Lambda function.

Monitoring & Security

Use access controls, logs, metrics, and throttling to manage API usage.

3. Serverless API Architecture

User / Client
↓

↓
Amazon API Gateway
↓

↓

4. Implementation Workflow

1. Create Lambda
Choose Python runtime and create a function.
2. Write handler
Return a status code and JSON response.
3. Deploy and test
Deploy the code and run a test event.
4. Create API
Create an HTTP API in API Gateway.
5. Connect services
Configure Lambda integration and a GET route.
6. Test endpoint
Deploy the API and test its invoke URL.
